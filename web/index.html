숫자가 0이거나 보이지 않는 이유

    
0 · 원본 보고:해당 수집 구간의 카운터가 0으로 보고됐습니다. 캐시가 읽히거나 캐시 대상 밖 입력만 추가되면 새 쓰기 없이 작업이 진행될 수 있습니다.

    
미기록:원본 로그에 쓰기 카운터가 없습니다. 코드 변경량·응답 길이·캐시 읽기량으로 쓰기 토큰을 추정하지 않습니다.

    
관측분:일부 요청만 카운터를 제공합니다. 표시 수치는 확인 가능한 부분이며 합계 전체가 아닙니다.

    
API 단가에 쓰기 가격이 있다는 사실과, CLI가 쓰기 사용량을 기록한다는 사실은 다릅니다. 미보고 캐시를 일반 입력으로 분류한 비용은 참고 환산입니다.
