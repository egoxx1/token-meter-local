## 새 테스트의 내용

진행 중/고정/종료/숨김/취소 측정 삭제, 500개 선택 삭제, 핀 해제, 다른 측정 보존, 전체 측정만 삭제 시 누적/작업 보존, 잘못된 확인 문구 거절, 실패 시 상태 복원, 500개 기록 한도 회수, 삭제 후 초기화 취소로 부활하지 않음.

전체 초기화 후 활성 토큰/비용/이력/측정/작업 0, 설정/사용자 단가/원본 파일 SHA-256 유지, 이전 데이터 백업, 원본 재스캔/재시작/Antigravity 재분석과 DB 복사 후 과거 사용량 재합산 없음, 새 요청만 새 journal에 저장, 늦게 발견한 옛 요청/무시각 요청 제외, 기존 진행 요청의 양의 증가분/캐시/THINKING, 두 번 초기화의 절대 기준점 보존, 가격/메타데이터만 교정됐을 때 새 토큰 없음.

요청 재시도 idempotency, 구 epoch 요청 거부, 원자 포인터 전환 전 준비·쓰기 오류, 포인터/활성 파일 손상·부재에 대한 fail-closed, symlink 거부, 사용자 대화 본문 sentinel 미저장, epoch별 커서 무효화, 인증/Origin/실제 HTTP Host 거부, GET/DELETE 무변경, 삭제된 선택 화면 fallback과 export 범위의 임의 확대 방지, 모의 VS Code에서 세 명령·고정 해제·전체 초기화.

UI에서는 진행 중 카드 삭제·취소, 선택 삭제, 측정만 전체 삭제, 확인 문구+동의가 없으면 전체 초기화 불가, 취소 무변경, 초기화 후 다섯 지표 토큰/금액 0, 빈 이력, 재수집 불변, 새 요청 1,100토큰 반영, 375/768/1440px 확인창 배치, 다른 클라이언트 삭제 후 오류 없는 화면 복귀를 확인했습니다.

## UI 검사의 한계와 수정 중 발견한 문제

일반 브라우저 탐색은 실행 환경 정책으로 ERR_BLOCKED_BY_ADMINISTRATOR가 발생했습니다. 정책을 변경하지 않고 about:blank에 실제 제품 HTML/CSS/JS를 넣고 실제 인증된 로컬 HTTP API에 fetch 브리지로 연결했습니다. 따라서 실제 URL 탐색·CSP·OS PiP까지 통과한 종단간 검사는 아닙니다.

검사 과정에서 이전 UI 버전 상수가 0.7.1로 남아 생긴 거짓 버전 경고, 시험 환경의 crypto.randomUUID 부재, 비동기 확인창 시험 대기 순서를 발견하고 수정했습니다. 최종 UI 보고서는 수정 후 성공 실행입니다. 범용 crypto.getRandomValues UUIDv4 fallback은 외부 라이브러리 없이 사용합니다. 삭제된 측정의 일반 export가 전체 누적으로 fallback하지 않게 범위를 제한했습니다.

모든 스크린샷·내보내기 표본은 합성 데이터입니다. 실제 앱을 1일 이상 사용하거나 사용자의 Antigravity 비공개 스키마를 실기 검증한 결과가 아닙니다.

## 배포 재검사

배포 검증 원문은 전체 ZIP의 verification/에 포함합니다. source ZIP을 새 폴더에 풀어 Node 전체·구문·새 삭제/초기화 UI·CLI 시작/종료/재시작을 검사합니다. VSIX CRC/XML/식별자/버전/새 모듈·명령·자산의 존재를 검증합니다. 최종 결과 수치는 verification/package-check.json 및 fresh-* 결과를 확인하세요. 실제 VS Code에 설치한 검증은 아닙니다.

## 남은 제한

실제 Windows/macOS/WSL/SSH·VS Code Extension Host, 사용자 원본 로그/계정/청구액, OS 최상위 PiP, 수십만 요청 장기 성능, 실제 외부 가격표/배포 서버 다운로드는 이번 변경에서 검증하지 않았습니다. 가격표와 수집 파서의 의미를 새로 검증한 버전도 아닙니다.

전체 초기화는 새 활성 데이터 구간을 시작하는 동작입니다. 이전 데이터·기준점 메타데이터가 로컬에 남으므로 보안 완전 삭제나 용량 회수 기능이 아닙니다. 초기화 후 0.8.0 미만 버전은 활성 포인터를 모르므로 사용하지 마세요. 원본 앱 기록을 지우지 않으며 계정 사용량/청구/한도를 초기화하지 않습니다.
