## 추가한 자동 검사

새 23개 테스트는 다음을 검사합니다. 기존 테스트는 새 표시와 버전 계약에 맞춰 갱신한 뒤 함께 실행했습니다.

- Antigravity 1319와 placeholder 매핑, 표시명과 숫자 ID 일치, 실제 모델 충돌 차단, 모델 속성 화이트리스트, 알 수 없는 숫자 ID의 잘못된 모델 상속 방지.
- 명시적 출력 합계와 세부값이 충돌할 때 중복 가산 방지. 입력·출력 가격 오류 독립 처리, 캐시 TTL 미상, 공식 표준 단가 우선 적용과 사용자 단가 우선권, 토큰×단가 계산 근거.
- 월별 JSONL 신규 기록·수정본·중복 제외, 재시작, 원본 로그 삭제 후 유지, ledger 유실 복원, 잘린 마지막 줄의 별도 보존, 완전한 손상 행의 실패 처리, 심볼릭 링크 거부, 쓰기 실패.
- 구버전 상태를 흉내 낸 ledger 자동 백업·가격 보완·DB 재분석, 요청 ID 보존, 재시작 유지, 수집 중 진단 상태가 빈 값으로 깜박이지 않음.
- 100건을 넘는 이력의 페이지 조회, 날짜·검색·상태 필터, 필터와 커서 일치 검증, 새 기록이 들어와도 과거 페이지 유지, 페이지와 무관한 전체 필터 내보내기, 인증된 HTTP 경로.

기존 VS Code 모의 테스트에 새 로그 폴더 열기·재분석 명령 실행 검사도 추가했습니다. 실제 운영체제 파일 탐색기가 열렸다는 뜻은 아닙니다.

## 화면 검사

기존 데모는 합성 CLI 로그 및 실제 임시 SQLite 파일의 80개 요청입니다. 새 가격/이력 검사에서는 합성 요청을 추가해 219개 요청을 만들고, 1319의 모델·단가 근거, 가격 일부 미계산 및 이유, 페이지 이동, 날짜/도구 필터 독립성, 전체 CSV/JSONL 내보내기와 실제 보존 파일 생성을 확인했습니다. 375/430/768/1280/1440px에서 페이지 가로 넘침을 확인했습니다.

브라우저의 실제 로컬 URL 탐색을 시도했으나 실행 환경 관리자 정책으로 ERR_BLOCKED_BY_ADMINISTRATOR가 발생했습니다. 정책은 바꾸지 않았습니다. 이후 기존 --offline 검사 방식으로 빈 문서에 실제 HTML/CSS/JS를 렌더링하고, 테스트용 fetch bridge를 통해 실제 인증된 루프백 HTTP API에 연결했습니다. 서버 인증·Host·Origin은 별도 HTTP 테스트에 포함됩니다.

따라서 이 검사는 실제 URL 탐색·CSP·운영체제 PiP까지 포함하는 완전한 종단간 검사가 아닙니다. 스크린샷은 합성 자료 화면이며 사용자 실제 기록을 수정한 결과가 아닙니다.

## 가격·모델 정보의 검증 범위

Google 공식 가격표의 Gemini 3.8/3.7/3.6 Flash Standard 2026년 구간(입력 $0.75, 캐시 읽기 $0.075, 출력 $3.75 / 100만 토큰)과 2027년 구간을 재확인했습니다. GPT-6 계열 및 내장 Claude의 표준 텍스트 단가도 확인 날짜·출처를 남겼습니다. 모든 외부 카탈로그 모델이나 모든 서비스 요금 모드를 검증한 것은 아닙니다.

Antigravity 내부 모델 번호는 Google 공식 계약이 아닌 고정 커밋의 공개 수집기 코드에서 확인했습니다. 1319 → Gemini 3.8 Flash Medium 등 9개 매핑에는 이 출처가 표시됩니다. 비공개 protobuf의 출력 합계를 우선하며, 불일치한 세부값은 진단으로 남깁니다. 합성 SQLite 시험만으로 실제 사용자의 모든 Antigravity 버전이 같은 의미를 갖는다고 증명할 수는 없습니다.

GPT-6의 장문 과금 적용 경계는 자동 판정하지 않습니다. 해당 단가는 단문 참고 조건을 표시합니다. 금액은 API 환산/추정 텍스트 토큰 비용이며 실제 구독 크레딧 차감·청구액·세금·도구 호출·저장료가 아닙니다.

## 설치·배포 검사

Python 표준 라이브러리로 VSIX와 소스 ZIP을 생성하고 CRC, XML, 확장 ID/버전/엔트리포인트, 새 파일과 Python bridge 포함 여부를 확인합니다. 최종 소스 ZIP을 새 폴더에 풀어 Node 테스트·구문 검사·독립 CLI와 세 UI 검사군을 다시 실행합니다. 세부 결과는 동봉된 테스트 로그와 PACKAGE-VERIFICATION.json에 기록됩니다.

## 미검증 및 남은 제한

실제 VSIX 설치/Extension Host, macOS·Windows·WSL/SSH, 실제 사용자 CLI/Antigravity DB와 공급자 청구서 대조, 실제 OS PiP, 장기간 대량 사용과 디스크 고갈, 실제 자동 배포 서버 연결은 검증하지 않았습니다. Antigravity .pb 형식, 실제 계정 한도·여러 기기 통합, 공식 모델 열거형 실시간 조회도 지원하지 않습니다.

사용 로그는 자동 삭제하지 않지만, 저장 용량과 파일 보존은 필요합니다. 월별 JSONL의 모든 수정본을 더하면 중복 과금처럼 보이므로 요청별 최신 기록만 합산해야 합니다. 종료된 재측정 결과는 고정되어 자동 재가격 산정되지 않습니다. 로그 보존과 전체 조회는 구현했으나 전체 JSON/RAM 집계 구조를 SQLite 분석 DB로 전환한 것은 아닙니다.
