## 핵심 확인

일반 입력/캐시 읽기/캐시 쓰기/출력의 토큰 및 정수 금액이 원래 총액과 일치하는지, THINKING 재분류로 총액이 늘지 않는지, 쓰기 0에서도 알려진 단가가 표시되는지, 여러 단가를 평균내지 않는지, 5분/1시간 쓰기 비용 묶음·미확인 TTL·옛 고정 측정·불완전 카운터를 안전하게 표시하는지 검사했습니다.

사진과 같은 단가를 사용한 10개의 합성 단문 요청은 일반 입력 100,692 + 캐시 읽기 2,149,888 + 쓰기 0 + 출력 10,619 = 총 2,261,199 토큰, $0.201384 + $0.4299776 + $0 + $0.106190 = $0.7375516을 산출합니다. 이 숫자는 사용자 데이터의 실증 결과가 아니라 명시한 테스트 입력의 산술 재현입니다.

UI에서는 100만/1,000 단위 전환, 모델별 근거, 고정바/PiP 렌더러, 원래 가격 매칭 검사, 설정, 역사 CSV/JSONL, 이름 측정, 상태바 고정, 모델 초기화 행의 캐시 정보 보존, 비교, 삭제를 검사했습니다. 375/430/768/1280/1440px에서 네 항목 표의 가로 넘침과 고정바 다섯 값의 화면 내 배치를 확인했습니다. 작은 화면은 줄을 바꿉니다.

삭제 시험은 진행 중/선택/숨김 측정 삭제, 확인 문구, 전체 초기화, 이전 기록 백업, 재수집 및 Antigravity 재분석 시 과거 사용량 재유입 방지, 다른 탭 삭제 상태 정리를 포함합니다.

## 제한

브라우저 정상 URL 탐색은 환경 정책으로 ERR_BLOCKED_BY_ADMINISTRATOR가 반환됐습니다. 정책을 변경하지 않고 about:blank에 실제 HTML/CSS/JS를 렌더링해 Python bridge로 인증된 실제 루프백 HTTP API에 연결했습니다. 이 방법은 정상 브라우저 탐색·CSP 종단간 검증이 아닙니다. HTTP 인증·정적 자산 경로·CSP 헤더는 별도 Node API 시험에서 검사했습니다.

PiP는 실제 앱의 렌더러를 별도 문서에 실행한 시험이며 OS 최상위 창 동작을 증명하지 않습니다. 스크린샷은 모두 합성 데이터입니다. 실제 VSIX 설치/Extension Host, 사용자 데이터, macOS/Windows/WSL/SSH, Antigravity 비공개 필드 의미, 실제 과금 일치, 대규모 장기 성능은 미검증입니다. 새로운 공식 단가 재확인 또는 외부 업데이트 배포 시험도 하지 않았습니다.

## 배포 검증

VSIX/source ZIP은 Python 표준 라이브러리로 작성하고 CRC, manifest 버전·확장 ID·진입점, 정적 shared billing module 경로, Python Antigravity reader와 필수 코드 포함 여부를 검사합니다. source ZIP을 새 경로에 풀어 341개 Node 테스트, 60개 JavaScript 구문 검사와 UI를 재실행한 결과는 전체 묶음의 verification에 보관합니다. 이 패키지 검사는 실제 VS Code 설치를 의미하지 않습니다.
