## UI 방식과 한계

실제 로컬 URL 탐색을 먼저 시도했지만 실행 환경 관리자 정책으로 `ERR_BLOCKED_BY_ADMINISTRATOR`가 반환되었습니다. 정책을 변경하지 않았습니다. 이후 빈 브라우저 문서에 제품 HTML/CSS/JS를 렌더링하고 인증된 실제 로컬 HTTP API로 연결하는 시험 브리지를 사용했습니다. 이것은 실제 URL 탐색/CSP까지 통과한 종단간 브라우저 시험이 아닙니다. 서버 인증·Host·Origin 등은 Node HTTP 테스트에서 별도로 검사합니다.

화면 이미지는 모두 합성 데이터이며 사용자 실사용량이나 실제 OS 최상위 창의 사진이 아닙니다. 실기 미검증: 실제 VS Code Extension Host 설치, macOS/Windows/WSL/SSH, 실제 Antigravity DB 버전별 필드 의미, 공급자 청구액 일치, Document PiP OS z-order, 수백만 레코드 장기 성능, 실제 배포 서버/카탈로그 자동 다운로드.

## 패키지 검증

Python 표준 라이브러리로 VSIX/소스 ZIP을 만들며 ZIP CRC, 확장 식별자·버전·엔트리포인트·필수 자산을 검사합니다. 새 `web/rates.js`와 `src/input-breakdown.js`가 VSIX와 소스에 포함됩니다. 최종 소스 ZIP은 새 폴더에 풀어 자동 테스트·구문 검사와 새 입력 UI 시험을 다시 실행합니다. 재검사 원문은 릴리스의 `verification/`에 보관합니다. 실제 VS Code에 설치한 결과로 해석하지 마세요.
