# Token Meter Local 0.10.1 — 검증 보고서

검증일: 2026-09-26. 공개 파일에는 개인 원본 DB, 장부, 진단 JSON, 접근키를 포함하지 않습니다.

## 확인한 범위

- 합성 SQLite에서 같은 본 호출의 primary/retry·step 관측은 한 번 세고, 서로 다른 재시도와 생성 행은 분리했습니다. 559개 호출 재현 사례에서 559개를 유지했습니다.
- 8MiB를 넘는 지원 메타데이터를 Node 및 Python 읽기 경로에서 시험했습니다. 제한은 BLOB당 16MiB입니다.
- 이전 v4 중복 장부 복구, 초기화 경계, 진행 중 측정 기준점, 재시작, WAL 추가 호출 및 Codex 회귀를 시험했습니다.
- 개발 기기의 macOS에서 0.10.1 VSIX를 설치하고 수집기를 실행했습니다. 로컬 Antigravity DB 수집 오류 0, 부분 수집 false, 복구 후 세션별 원본↔장부 대조 불일치 0을 관측했습니다. 기존 VS Code 창 재로드 후 확장 상태바도 확인했습니다. 이 수치는 해당 시점의 로컬 관측입니다.
- 소스 ZIP을 별도 폴더에 풀어 동일한 테스트와 구문 검사를 실행하고, VSIX 매니페스트·아카이브 CRC·파일 체크섬을 검사했습니다.

## 한계

비공개 Antigravity 형식의 필드 의미와 실제 공급자 청구액은 독립 인증하지 못했습니다. 다른 기기, Windows, 모든 앱 버전, 삭제된 원본 및 장기 운영을 검증한 결과도 아닙니다. 이전 버전의 합성·브라우저 검사 내역은 [0.10.0 보고서](TEST-REPORT.md)에 별도로 보존합니다.
