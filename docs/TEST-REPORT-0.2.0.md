## 재검토에서 발견·보완한 사항

**공급자와 모델 이름 혼동:** 같은 모델 문자열에 다른 과금 공급자의 기본 가격이 붙을 가능성을 줄이기 위해 `modelProvider`를 가격 키에 포함했습니다. 타사 게이트웨이를 직접 API 요금으로 추정하지 않습니다. 모델별 표와 CSV에도 공급자를 분리합니다.

**Gemini 하위 에이전트 파일 누락:** 기존 `session-` 접두어 필터는 `chats/<부모 세션>/<하위 에이전트>.jsonl`을 놓칠 수 있었습니다. 공개 코드의 경로 구조에 맞춰 수집하고 부모 세션 힌트를 남깁니다. `$set.messages` 체크포인트의 사용량도 정규화합니다. 해당 형식의 합성 로그로 검증했으며 실제 CLI 바이너리와의 통합 시험은 아닙니다.

**Gemini ID 혼동:** 동일 메시지 ID를 가진 서로 다른 세션을 한 요청으로 처리할 수 있었습니다. ID에 세션을 포함하고 v1→v2 백업/이관 및 재조회로 보완했습니다. 이미 삭제된 원본에서 과거에 놓친 기록을 복구할 수는 없습니다. 외부 도구로 세션 ID를 바꿔 같은 대화를 복제한 경우까지 전역 중복 판정을 보증하지 않습니다.

**같은 합계의 캐시 변경 무시:** 스트리밍/수정 기록에서 합계는 같고 캐시 구성이 변한 경우도 반영합니다. 단순 중복은 재가산하지 않습니다.

**과거 부분 단가 변경:** 일부 가격만 알던 과거 요청을 새 표로 통째로 재계산하지 않게 했습니다. 저장된 단가를 보존하고 단가 자체가 없던 요청만 채웁니다. 프로그램이 꺼진 사이 등록된 가격도 시작 시 미정 요청에 적용합니다.

**구형 수집기 잔존:** 확장 활성화 시 수집기 버전을 비교하여 이전 버전 종료·교체를 요청합니다. 더 높은 버전으로 실행 중이면 자동 다운그레이드하지 않습니다. 갱신 중인 수집기의 종료는 진행 중 다운로드/저장의 제한 시간까지 대기할 수 있습니다.

## 새 기능의 검증 내용

### 사용량/모델

OpenAI 호환 캐시·추론 부분집합, Anthropic 캐시 TTL, Gemini thoughts 합산, 명시적 로컬 Ollama의 API 토큰 비용 0 처리, 공급자별 정확한 모델 ID, OpenRouter 조건부 단가 경계, 일반 JSONL/인증된 HTTP 가져오기, 재시작·중복 요청, 원문/키 필드 폐기, 멀티모달/불명확한 입력의 미정 표시를 시험했습니다.

### 모델·가격표 자동 갱신

유효한 합성 피드, 단위 변환, 명시적 무료 단가와 누락 값 구분, 장문 tier, 지원하지 않는 조건, 빈/잘못된 목록, 304, 네트워크 실패, 마지막 정상 캐시 복구, 동시 요청 합치기, 꺼짐 상태의 요청 0건, 로컬 API를 통한 갱신 후 금액 반영을 검증했습니다. 조건 정보가 적은 커뮤니티 표가 기존 장문 규칙을 제거하지 못하게 했습니다.

**실제 models.dev/OpenRouter HTTPS 다운로드는 이 컨테이너의 외부 DNS 제한으로 끝까지 실행하지 못했습니다.** 브라우징 도구로 공개 자료를 확인했지만 그것이 앱의 실제 네트워크 성공 시험과 같은 것은 아닙니다. 자동 갱신 테스트는 주입한 모의 전송 함수를 사용했습니다. 공급자의 향후 스키마 변경, 인증 정책, 요금표 전체 정확성은 보증하지 않습니다.

### 프로그램 업데이트

유효한 Ed25519 서명, 변조/다른 키/다른 알고리즘, 만료/미래 날짜/버전 하향/다른 앱, 허용하지 않는 호스트, VSIX 구조/식별자/버전, SHA-256·크기 불일치, 다운로드 후 파일 변조, 캐시 재시작 후 재검증을 시험했습니다.

자동 다운로드는 **검증된 VSIX를 준비하는 것까지**이며 코드 실행은 하지 않습니다. VS Code 확장 테스트에서는 검증된 경로가 `workbench.extensions.installExtension`에 전달되는 것을 **VS Code API 모의 객체**로 확인했습니다. 실제 Extension Host 설치, 게시자 경고, 운영체제 권한, 설치 후 재로드/다음 버전의 데이터 이관까지 시험한 것은 아닙니다.

공개 배포 서버와 Marketplace 항목이 없으므로 **배포처 미설정 상태에서 미래 버전을 실제 자동 배포하는 서비스는 제공되지 않습니다.** 서명 키·HTTPS 호스트를 별도로 준비해야 합니다. 독립 소스판 자동 덮어쓰기/자가 재시작은 구현하지 않았습니다.

### UI

기존 18개 검사에 모델 목록 개수/검색·공급자 구분, 미설정 앱 업데이트 안내 3개를 추가했습니다. 375/430/768/1280/1440px에서 페이지 가로 넘침을 검사했습니다. 프롬프트/태그 문자열은 실행되지 않는 텍스트로 렌더링됩니다.

브라우저의 URL 탐색 제한 때문에 HTML/CSS/JS를 빈 문서에 렌더링하고 테스트용 fetch 브리지로 실제 루프백 HTTP API에 연결했습니다. 실제 브라우저 탐색과 브라우저 CSP 강제 적용까지 포함하는 완전한 종단간 시험은 아닙니다. PiP는 컴포넌트 렌더링/지원 불가 안내만 시험했으며 실제 OS 최상위 창 동작은 미검증입니다.

## 남은 위험 / 다음 검증

실제 사용자의 Codex·Claude·Gemini 버전별 기록, 계정과 과금 명세서 대조, Windows/macOS/WSL/SSH, 장기간·대량 데이터와 장애 복구, 실제 공개 배포 서버와 설치, 멀티모달 및 모든 공급자/지역/과금 모드가 남아 있습니다. 저장 구조는 전체 JSON 스냅샷이며 대규모 운영용 데이터베이스로 바꾸지 않았습니다.

수정 전후의 테스트 통과는 알려진 입력 사례에서의 결과입니다. 모든 수집 누락, 이중 계측, 로그 유실, 가격표 오류, 공급자별 숨은 비용이 제거됐다고 주장하지 않습니다.
