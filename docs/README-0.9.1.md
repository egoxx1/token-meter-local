## 이번 변경

화면을 사용량 명세서 중심으로 정리했습니다. 상단의 **비용 / 토큰 / 입력 중 캐시 재사용 비중** 요약과 아래의 **일반 입력 / 캐시 읽기 / 캐시 쓰기 / 출력**을 같은 데이터에서 계산합니다. 단위는 표 머리글에 모으고, 토큰·단가·금액을 수직 정렬했습니다. 데스크톱·작은 화면·미니바의 색상과 간격도 맞췄습니다.

**캐시 쓰기는 코드 파일 쓰기가 아닙니다.** 패치를 생성하거나 파일을 저장했다고 캐시 쓰기 토큰이 자동으로 증가하지 않습니다. 서버가 다음 요청에 재사용할 프롬프트를 캐시에 저장한 수치와 연결되는 항목입니다.

| 원본 카운터 상태 | 토큰 표시 | 금액 표시 |
|---|---|---|
| 명시적으로 0 | `0` + 원본 보고 · 0 | `$0.000` |
| 카운터 없음, 관측된 쓰기 없음 | **미기록** | **분리 불가** |
| 양수 카운터 확인 | 해당 토큰 수 | 해당 쓰기 단가 적용 |
| 일부 요청만 카운터 있음 | 관측분 + 상태 안내 | 관측분 비용 |

기존 화면은 누락된 카운터를 `0 (참고)`로 표시할 수 있었습니다. 0.9.1은 이 상태를 명확히 바꿉니다. 가격표에 쓰기 단가가 존재하는 것과 해당 요청에 쓰기 토큰이 보고되는 것은 별개입니다. **캐시 쓰기란?** 버튼에서 설명과 공식 자료를 확인할 수 있습니다.

## 설치 · 기존 버전 교체

VS Code에는 **`token-meter-local-0.9.1.vsix` 하나**만 필요합니다.

1. 확장 → `…` → **Install from VSIX…**에서 파일 선택.
2. 작업 저장 → **Developer: Reload Window**. 기존 브라우저 대시보드 탭 닫기.
3. 하단 **TM**으로 다시 열고 **LOCAL / 0.9.1** 확인. 구버전이면 **Token Meter: Restart Collector**.

**`~/.token-meter`, `active-data.json`, `data-epochs`는 삭제하지 않습니다.** 이번 설치는 사용량 초기화나 과거 가격표 교체를 하지 않습니다. 각 AI 프로그램 폴더에 파일을 복사할 필요도 없습니다.

소스 ZIP으로 실행할 때는 압축 안 **token-meter** 폴더에서:

```sh
node bin/cli.js stop
node bin/cli.js serve --open
```

Node.js 20+ 또는 VS Code 1.95+가 필요합니다. Antigravity SQLite 읽기에는 실행 Node의 `node:sqlite` 또는 SQLite 모듈을 가진 Python 3가 필요합니다. 외부 실행 npm 의존성은 없습니다.

## 표시와 계산의 의미

```text
TOTAL = IN(일반 입력) + CACHE READ + CACHE WRITE + OUT
OUT = THINKING을 포함한 전체 출력
```

확인되지 않은 캐시 카운터는 분류의 불확실성으로 표시합니다. 기존 방식대로 캐시로 구분되지 않은 입력 잔여량을 일반 입력 단가로 환산할 수 있지만, 이는 **참고 환산**이며 실제 캐시 쓰기 0이나 정확한 청구액을 의미하지 않습니다. 이번 변경은 카운터를 만들어 더하거나 과거 토큰·가격을 변경하지 않습니다. 총량은 보존합니다.

상단 캐시 비중은 **캐시 읽기 토큰 / 캐시 포함 입력 토큰**입니다. 요청 성공률·요청 적중률·전체 계정 통계가 아닙니다. 필요한 카운터가 없으면 미확인으로 표시합니다.

모델·요금 모드·단가 조건이 섞이면 혼합 그룹으로 표시합니다. 단가 기본 단위는 **USD / 100만 토큰 (1M = 1,000,000)**이며 실제 사용금액과 별개입니다. THINKING은 OUT에 한 번 포함하고 세부값은 펼쳐서 확인합니다.

## 기존 기능과 한계

도구·모델별 재측정, 측정 삭제, 전체 초기화, 사용 이력/수정 로그, CSV/JSONL, 적용 단가/모델 연결 검사, 선택적 카탈로그 갱신은 유지했습니다. 캐시 설명 버튼은 사용자가 공식 문서 링크를 누르기 전에는 외부 요청을 하지 않습니다.

이 버전은 **파서나 단가 표를 전부 새로 검증한 버전이 아닙니다.** 사용자 실제 CLI 로그/Antigravity DB·구독 청구·macOS/Windows·실제 VS Code 설치·OS 최상위 PiP 검증은 남아 있습니다. 비공개 Antigravity 필드 해석, 없는 카운터, 실제 과금 경로 차이를 화면 디자인으로 해결하지는 못합니다. 금액은 실제 결제가 아닌 **API 환산/추정 토큰 비용**입니다.

기술 필드 `input`은 캐시 포함 전체 입력, 화면 `IN`은 `normalInput`입니다. 캐시 쓰기 필드가 미기록이어도 하위 호환을 위해 원시 관측 합계는 0일 수 있으므로 내보내기/연동에서는 `cacheWriteKnown`, `inputBreakdown.cacheWriteUnreportedRecords`, `billingView.components[].usageState`를 함께 읽어야 합니다. 숫자 0만으로 미사용을 판정하지 마세요.
