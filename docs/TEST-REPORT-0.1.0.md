## Node 테스트의 핵심 내용

**사용량:** Codex 누적 증가분, 중복 스냅샷, 모델 전환, 카운터 감소, fork 이전 기록 제외, 과거 합계 모델 미상, 캐시/추론 중복 방지, 하위 에이전트 표시. Claude 입력·캐시 항목 정규화, 누락 TTL, 식별자 대체/누락, 미완료 기록. Gemini thoughts, tool 토큰 합계, JSON 스냅샷과 JSONL 메타데이터/되감기.

**계산:** 정수 비용 산출, 미지원 모델 미정 처리, 입력 일부 미정이어도 출력 비용 유지, 추론 강도의 임의 배수 금지, Fast 규칙, 정확한 모델/날짜 버전 매칭, 타사 게이트웨이 기본값 미적용, 명시적 무료 단가, 사용자 단가 적용 시점, 스트리밍 최종값 장문 구간 재평가, 기존 단가 보존.

**저장:** 중복 파일, 재스캔, 프로세스 재시작, UTF-8 중간 행, 새 바이트만 읽기, 스트리밍 갱신, JSON 교체, 원본 삭제 후 누적 유지, 병렬 저장 순서, 과거 파싱 오류 진단 유지, 심볼릭 링크 제외, 오염된 ledger 거부. 프롬프트 sentinel이 ledger·체크포인트·CSV에 남지 않음을 검사했습니다.

**API/표시:** 실제 루프백 HTTP 서버에서 인증, Host/Origin, 허용하지 않는 경로/메서드, 설정 검증, 동시 단가 추가, 작업 중복 시작 방지, 내보내기 범위와 CSV 수식 주입 방지, 이중 실행 잠금, 종료 시 runtime/lock 정리, 기록 없음과 0원 구분. VS Code는 API 모의 객체로 활성화·상태바·대시보드 명령·필터·해제를 시험했습니다.

## UI 테스트의 의미

합성 데이터는 Codex 36개, Claude 20개, Gemini CLI 16개로 총 **72개 고유 사용량 기록**입니다. 복제 기록은 합계를 늘리지 않습니다. 스크린샷 수치는 모두 이 데모 데이터입니다.

이 실행 환경의 Chromium은 관리자 정책으로 모든 URL 탐색이 차단되어 있습니다. 정책을 변경하지 않고, 앱 파일을 빈 브라우저 문서에 렌더링한 뒤 테스트용 fetch 브리지를 통해 실제 로컬 API에 연결했습니다. 필터, 설정, 작업 측정, CSV/JSON 내보내기, 사용자 단가, 375/430/768/1280/1440px 화면, 오류 없는 렌더링을 확인했습니다. 화면 테스트는 **브라우저 탐색부터 시작하는 완전한 종단간 테스트가 아닙니다.**

미니바는 같은 렌더링 함수를 별도 문서에 적용해 UI를 검사했습니다. 접근할 수 없는 PiP 환경에서 안내가 표시되는 것도 확인했습니다. **Document Picture-in-Picture의 실제 창 생성, OS 최상위 유지, 부모 탭 수명 동작은 실기 검증하지 못했습니다.**

## 미검증 또는 미지원

- 실제 VS Code에 VSIX를 설치하여 Extension Host에서 실행하는 실기 검증.
- 사용자의 Codex / Claude Code / Gemini CLI 버전, 원본 실제 로그 및 과금 명세서 대조.
- Windows / macOS 실기, WSL / SSH 포트 전달, 백그라운드 브라우저 탭의 타이머 제한.
- 대량 로그 환경의 CPU·RAM·I/O 성능과 장기 실행 내구성.
- GPT-6 API 장문 적용 경계 자동 판정. 기본값은 short-context 참고 가격입니다.
- Antigravity 내부 사용량, 웹 채팅, 계정 구독 한도/잔여량, 실제 청구액.

이 결과는 해당 합성 사례와 검사 범위에서 통과했다는 뜻입니다. 모든 CLI 버전의 지원, 실제 청구 정확도, 설치 무오류를 보증하지 않습니다.
