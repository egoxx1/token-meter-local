## 개발 중 시험 수정

버전을0.9.1로 올리자 기존 업데이트 테스트의 미래 버전0.9.1이 현재 버전과 같아졌습니다. 이를0.9.2 시험 값으로 바꾼 뒤 기존341개를 통과했습니다. 실제 updater 구현은 바꾸지 않았습니다.

초기화한 데모에 동일 요청 ID를 다시 사용하면 과거 ID가 재사용되는 것으로 제외되는 정상 동작 때문에 재실행 시험이 실패했습니다. 전용 데모를 각각 새로 시작하고 신규 프리뷰 시험의 ID에 실행별 UUID를 붙여 격리했습니다. 정상 중복 방지 구현을 우회하거나 변경하지 않았습니다.

## 환경 제한

일반 Chromium URL 탐색은 관리자 정책의 ERR_BLOCKED_BY_ADMINISTRATOR로 차단됐습니다. 정책을 변경하지 않고 about:blank에 실제 HTML/CSS/JS를 렌더링하고 실제 인증된 루프백 API를 시험용 fetch 브리지로 연결했습니다. 따라서 브라우저 탐색·CSP·실제 OS PiP를 포함하는 완전한 종단간 시험은 아닙니다.

실제 VSIX 설치/Extension Host, macOS/Windows/WSL/SSH, 사용자 로그의 캐시 카운터 존재 여부, Antigravity 비공개 필드 의미, 실제 구독/청구 금액, 장기 대용량 성능을 새로 검증하지 않았습니다. 기존 파서와 가격표를 전부 재검증한 버전도 아닙니다.

## 배포

VSIX/source ZIP의 CRC·manifest·버전·진입점·필수 파일을 검사합니다. 소스 ZIP을 새 폴더에 풀어 전체 Node/구문 검사를 재실행한 원문은 전체 묶음 verification에 보관합니다. 배포용 이미지/HTML은 합성 화면이며 외부 폰트·사용자 대화·원본 코드·runtime 접근키를 포함하지 않습니다. 공개용 업로더는 모의 검사와 로컬 파일 검사만 수행하며 실제 GitHub 게시를 뜻하지 않습니다.
