# Token Meter Local 0.5.0

**Codex · Claude Code · Antigravity 로컬 기록의 IN / OUT / TOTAL 토큰과 비용, 모델별 재측정, 근거 있는 가격 표시와 영구 사용 로그.**

이번 버전은 `+ ?`를 숨기는 패치가 아닙니다. 가격 적용 불가 원인을 분리하고, Antigravity 모델 번호 1319의 출처 있는 매핑을 추가하며, 기존 기록의 재분석과 보존·전체 조회를 구현했습니다. 금액은 **API 텍스트 토큰 환산/추정액**이며 실제 구독료·크레딧 차감·카드 청구액이 아닙니다.

## 1. 설치 — VSIX 하나만 필요

1. `token-meter-local-0.5.0.vsix` 다운로드.
2. VS Code → 확장 → 오른쪽 위 `…` → **Install from VSIX…** → 파일 선택.
3. 작업 저장 → 명령 팔레트에서 **Developer: Reload Window** 실행.
4. **이전에 열어 둔 대시보드 탭을 닫고**, VS Code 하단 TM을 눌러 새로 엽니다.
5. 왼쪽 위가 **LOCAL / 0.5.0**인지 확인합니다. 0.3.0/0.4.0이면 **Token Meter: Restart Collector** 후 TM으로 다시 엽니다.
6. 최초 실행은 기존 자료를 백업하고 Antigravity DB를 다시 읽습니다. **가격 계산 상태 → Antigravity 기록 재분석**으로 수동 재분석도 가능합니다.

**기존 `~/.token-meter`를 삭제하지 마세요.** Codex/Claude/Antigravity 앱 폴더에 소스를 복사할 필요가 없습니다. 소스 ZIP은 수정·독립 실행용입니다. Marketplace나 운영 배포 서버는 연결되어 있지 않아 이번 파일은 수동 설치해야 합니다.

실제 VS Code Extension Host 설치와 Windows/macOS 실기는 이 빌드 환경에서 수행하지 않았습니다. 아래 테스트 결과는 이 한계를 대신하지 않습니다.

## 2. 가격 표시가 달라진 부분

| 표시 | 의미 |
|---|---|
| 단가 적용 완료 | 필요한 항목을 저장된 단가로 산출함. 실제 청구 일치의 인증 아님 |
| 참고 조건으로 환산 | 장문 경계 미확인, 사용자 지정, 커뮤니티 단가 등 참고 조건 포함 |
| 일부 항목 계산 불가 | 계산 가능한 항목의 소계만 표시. 제외 금액은 0원이 아님 |
| 계산 불가 | 모델·단가·토큰 근거가 부족해 금액을 만들지 않음 |
| `—` | 이 범위의 관측 기록 없음. 사용량 0으로 확인된 것이 아님 |

**입력과 출력은 독립 판정합니다.** 출력 세부값 문제 때문에 정상 입력 비용까지 미확정 처리하지 않습니다. 캐시 쓰기 유지시간이 빠진 경우 그 항목만 제외하고 입력의 나머지와 출력은 계산합니다. 충돌한 토큰에 계산한 금액을 ‘확인분’에 섞지 않습니다.

상단 **가격 계산 상태**에서 사유별 건수와 제외된 토큰을 확인합니다. **사용 기록 → 계산 근거**에는 일반 입력·캐시 읽기·캐시 쓰기·출력 각각의 토큰, USD/100만 토큰 단가, 산출액, 가격 원문, 기준일, 재확인일, 모델 연결 근거가 표시됩니다.

출력 가격에는 thinking이 포함됩니다. 캐시 시간당 저장료, 도구 호출료, 세금 등은 별도이며 이 도구의 토큰 비용에 포함하지 않습니다. 2027년부터의 공식 가격도 날짜 구간을 분리해 유지합니다. UTC 날짜 경계는 로컬 계산 규칙이지 실제 청구 시간대 검증이 아닙니다.

출처: https://ai.google.dev/gemini-api/docs/pricing

OpenAI GPT-6와 내장 Claude 표준 텍스트 단가도 공식 가격표와 대조했습니다. **GPT-6 장문 추가요금의 적용 경계를 확정하지 못해 단문 참고 단가로 표시**하며 임의의 경계를 넣지 않았습니다. 추가 카탈로그 수천 모델의 단가 전체를 수동 검증한 것은 아닙니다. ‘공식 재확인’은 해당 표준 가격 스냅샷의 출처이지 과거 청구서 일치나 비공개 DB 정확도의 인증이 아닙니다.

### 가격 우선순위와 기존 기록

명시적 사용자 단가 → 이번에 공식 확인한 내장 규칙 → 외부 카탈로그 → 기타 내장 참고 규칙 순서입니다. 공급자·모델 ID·모드·시점을 구분합니다. OpenRouter 가격을 Google/OpenAI 직접 API에 적용하지 않습니다.

과거 가격 스냅샷은 보존합니다. 예외는 이번 수리 과정의 같은 날짜 공식 단가로 커뮤니티 단가를 교정하는 경우와, 모델명이 해소되어 올바른 규칙을 적용하는 경우입니다. **교정 전 데이터는 백업과 보존 로그의 이전 수정본에 남습니다.** 같은 숫자의 공식 스냅샷은 재확인 근거만 추가할 수 있습니다. 과거 청구 당시의 실제 가격을 복구하는 기능은 아닙니다.

## 3. Antigravity 모델과 출력 수리

**1319 → Gemini 3.8 Flash · Medium**으로 연결합니다. 1318/1320(High/Low), 3.7 Flash의 1298~1300, 3.6 Flash의 1071~1073도 명시적으로 연결합니다. `model_placeholder_m319` 같은 대응 표기도 처리합니다.

이 매핑은 **ccusage의 공개 구현을 근거로 한 참고 매핑**입니다. Google이 보장한 영구 enum 규약이 아닙니다. UI와 로그에 원래 번호, 모델명, 출처를 함께 남깁니다. 모르는 번호를 근처 모델이나 세션의 마지막 모델에 억지로 붙이지 않습니다.

생성 기록과 단계 기록의 같은 모델을 이름/번호만 다르다는 이유로 충돌 처리하던 경로를 보완했습니다. 진짜 다른 모델 관측은 계속 충돌로 남깁니다.

지원 DB 형식의 **별도 출력 합계(field 3)**를 과금 출력으로 사용합니다. 세부 9/10의 합이 맞지 않으면 원본 카운터를 보존하고 세부 추론값은 확인 불가로 표시합니다. 합계를 `max()`로 키우거나 추론을 다시 더하지 않습니다. 비공개 형식의 해석이므로 실제 앱 버전별 호환성을 보증하지 않습니다.

원본 DB가 남아 있으면 이전 체크포인트를 무효화하여 다시 읽고, 예전 과대 출력/잘못된 모델 충돌을 수정본으로 기록합니다. 원본이 없으면 복구 가능한 모델 매핑만 적용하고, 근거가 부족한 비용을 임의로 확정하지 않습니다.

자동 탐색: `~/.gemini/{antigravity,antigravity-cli,antigravity-ide}/conversations/*.db`. `ANTIGRAVITY_DATA_DIR` 또는 로컬 config의 `roots.antigravity`로 변경할 수 있습니다. 수집기와 로그가 같은 컴퓨터/사용자 환경에 있어야 합니다.

`node:sqlite`를 쓸 수 있는 Node 런타임, 또는 SQLite 모듈이 있는 Python 3가 필요합니다. VS Code 내부 Node에 SQLite가 없으면 Python fallback을 시도합니다. 구형 `.pb`만 있는 환경은 미지원입니다. 프로젝트·하위 에이전트 관계는 Antigravity에서 여전히 미분류입니다.

## 4. 사용 기록을 계속 보존

저장 기본 위치:

```text
~/.token-meter/
  ledger.json                    요청별 최신 관측값과 수집 체크포인트
  ledger.pre-0.5.0.json           최초 수리 전 기존 ledger 백업
  usage-log/
    2026-09.jsonl                 관측한 UTC 월 기준; 이후 월도 자동 생성
    2026-10.jsonl
  measurements.json              재측정 기준점·진행/종료 결과
```

**기록 자동 삭제·최근 N건만 보존하는 정책은 없습니다.** 수집할 때 새 요청을 한 줄 추가하고, 같은 요청의 토큰·모델·단가가 수정되면 새 `revision`을 추가합니다. 아무 변화 없는 재스캔은 줄을 추가하지 않습니다. 재시작해도 보존합니다. 월별 파일의 모든 줄을 비용으로 더하면 수정본이 중복 합산되므로, **요청 ID별 최신 수정본만 합산**해야 합니다.

최초 실행 때 기존 ledger의 최신 기록을 `import`로 남깁니다. 과거 버전이 저장하지 않았던 수정 과정이나 삭제된 원본까지 복원하지는 못합니다. 원본 로그를 삭제해도 이미 보존한 관측값은 남습니다.

기록은 fsync 후 ledger 체크포인트를 저장합니다. 쓰기 실패는 오류로 노출합니다. 중간에 끊긴 마지막 줄은 `.torn-*`로 보관한 뒤 마지막 완성 줄까지 복구합니다. 완성된 줄의 손상은 임의 삭제하지 않고 오류로 중단합니다. 디스크 고장·악성 삭제에 대한 백업 서비스는 아니므로 데이터 폴더를 별도로 백업하세요. 프로그램이 꺼져 있는 동안의 미기록 사용량을 알 수는 없습니다.

### 화면에서 과거 기록 보기

**사용 기록 · 자동 보존**은 상단 누적/재측정 필터와 독립적입니다. 기본은 전체 기간·전체 도구입니다. 시작일/종료일, 도구, 모델/요청 검색, 계산 상태로 조회하고 페이지당 25/50/100/200건을 볼 수 있습니다. 이전·다음 페이지로 예전 기록까지 조회합니다. 과거 페이지를 보고 있으면 실시간 수집이 최신 페이지로 강제 이동시키지 않습니다.

`조회 전체 CSV / JSONL`은 현재 페이지가 아니라 **조회 조건에 맞는 요청 전체의 최신값**을 내보냅니다. 원본 월별 보존 로그는 수정 이력을 포함하고, 화면 내보내기는 최신 요청값만 포함하는 서로 다른 자료입니다.

명령 팔레트의 **Token Meter: Open Usage Log Folder**로 보존 폴더를 열 수 있습니다. 프롬프트·응답·코드·API 키는 로그에 저장하지 않습니다. 모델·시각·토큰·단가·요청/세션 ID·프로젝트 메타데이터도 민감할 수 있으므로 공개 업로드하지 마세요.

## 5. 기존 기능 유지

도구/모델별 `0부터 재측정`, 초기화 취소, 이름 붙인 측정, 종료 결과 보관, 비교, PASS/FAIL 수동 메모, 상태바 고정, CSV/JSON 내보내기를 유지합니다. **이미 종료한 측정은 당시 값으로 고정**하고 이번 재분석으로 덮어쓰지 않습니다. 최신 교정값은 전체 사용 기록에서 확인하세요.

대시보드·고정 하단바·PiP 미니바·VS Code 상태바 모두 IN 토큰/비용, OUT 토큰/비용, TOTAL 토큰/비용을 표시합니다. VS Code 원 단위 표시는 `"tokenMeter.tokenDisplay": "exact"`입니다. 창이 좁으면 VS Code 자체가 상태바를 자를 수 있습니다. PiP는 지원 브라우저와 부모 탭이 필요하며 OS 네이티브 창이 아닙니다.

모델/가격표 자동 갱신은 동의 후 24시간 주기로, 기본은 꺼짐입니다. 공개 카탈로그는 참고 자료이고 이번 공식 검증 단가보다 우선하지 않습니다. 서명된 프로그램 updater는 있으나 배포 서버/Marketplace 미연결입니다.

## 6. 독립 실행·개발

Node.js 20+에서 소스 ZIP의 **token-meter** 폴더 안에서 실행합니다. Antigravity에는 SQLite 런타임/Python 조건도 필요합니다. 외부 npm 패키지 설치는 없습니다.

```sh
node bin/cli.js serve --open
# 실제 데이터와 분리된 합성 데모
node bin/cli.js demo --open
# 다른 터미널에서
node bin/cli.js history --provider antigravity
node bin/cli.js reanalyse-antigravity
node bin/cli.js diagnose-antigravity
node bin/cli.js stop
npm test
npm run check
npm run package
```

기본 데이터 폴더는 `TOKEN_METER_HOME` / `--data-dir` / VS Code `tokenMeter.dataDirectory`로 바꿉니다. API는 `127.0.0.1` 전용이고 접근키·Host·Origin을 검사합니다. `runtime.json`과 `#key=` 주소는 공유하지 마세요.

## 7. 남은 제한

실제 사용자 Antigravity DB/계정, 실제 VS Code 설치, macOS/Windows/WSL/SSH, 실제 청구서 대조는 미검증입니다. 테스트는 합성 CLI 기록과 실제 임시 SQLite 파일에 넣은 합성 protobuf로 수행합니다. 지원하지 않는 DB 구조는 가격 표시 변경으로 해결되지 않습니다.

사용량 저장소는 여전히 전체 JSON ledger와 메모리 인덱스입니다. 보존 JSONL을 추가했지만 SQLite 기반 장기 집계 DB로 바꾼 것은 아닙니다. 요청 수가 매우 많으면 시작·검색·집계 비용과 디스크 사용이 늘며 대규모 장기 성능을 보증하지 않습니다. 기록을 자동 삭제하지 않으므로 디스크 공간을 관리해야 합니다.

API 환산액은 구독 잔여 한도나 실제 청구액이 아닙니다. 웹 채팅, 여러 PC 합산, 구형 Antigravity PB, 이미지/오디오/서버도구/캐시 저장 요금·세금·환전 수수료는 제외합니다. 정말 없는 모델 정보나 단가는 ‘확실한 숫자’로 만들어 내지 않습니다.
