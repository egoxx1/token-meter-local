## 재현한 오류

잘못된 모델의 저장 단가를 전달하면 이전 코드가 현재 모델 이름으로 다시 표시하면서 가격은 이전 모델의 것을 쓰는 경로를 재현했습니다. 공급자/모드/유효기간 불일치, 로컬 무료 단가의 원격 재사용, 도구별 사용자 가격의 다른 도구 유출도 별도 사례로 검사했습니다. 일부 테스트는 새 진단 데이터가 존재하는지 검사하므로 초기 실패 수가 곧 서로 다른 제품 버그 개수를 뜻하지는 않습니다.

교정 후 올바른 모델·조건 규칙을 선택하거나 단가 미확인으로 남김, 정상적인 과거 사용자 단가 보존, 가짜 resolvedModel만 바꿔도 실제 규칙의 다른 모델이 숨겨지지 않음, 날짜 별칭 근거 노출을 확인했습니다. 토큰 수가 그대로인 시각/컨텍스트 보완에도 유효기간·장문 조건이 갱신됩니다.

불일치 자료를 가진 임시 ledger를 실제 파일로 저장하고 시작 교정/백업/월별 수정본/재시작 시 중복 revision 방지를 검사했습니다. GET 진단 API의 무인증 거부, POST 비지원과 읽기 전용성, 본문 sentinel 미노출을 검사했습니다. 종료된 측정 보존과 메타데이터만 보완된 재측정의 소비량 불변은 기존 회귀 테스트에 포함됩니다.

## UI 검사

검색 결과에 Standard/Batch/Flex가 명시적으로 구분되는지, 적용표를 1,000토큰 기준으로 바꿔도 검색표 모든 열은 100만 단위를 유지하는지 확인했습니다. 같은 모델 이름이 OpenRouter 등 여러 공급자에도 있을 수 있으므로 테스트는 정확한 모델·공급자/모드 범위를 검사합니다.

실제 합성 데모 80건에 날짜 버전 모델 요청 1건을 인증된 사용량 API로 추가하여 총 81건을 검사했습니다. 관측 ID와 실제 가격표 ID를 따로 표시하는 상세, 진단 JSON 내려받기, 375/768/1440px에서 새 영역 페이지 넘침 없음, 데스크톱 진단 표의 가격 열 표시를 확인했습니다. 기타 기존 UI는 375/430/768/1280/1440px 검사를 포함합니다.

일반 브라우저 URL 탐색 시 `ERR_BLOCKED_BY_ADMINISTRATOR`가 반환되었습니다. 정책을 변경하지 않았습니다. **about:blank에 실제 제품 HTML/CSS/JS를 로드하고 인증된 실제 루프백 HTTP 서버에 테스트 fetch bridge로 연결**했습니다. 브라우저 탐색/CSP를 포함한 종단간 검증은 아닙니다. 모든 스크린샷·내보내기 표본은 합성 데이터입니다.

## 패키지 검사 및 재실행

VSIX/소스 ZIP의 압축 CRC, XML, 식별자·버전·엔트리포인트와 새 `src/rate-audit.js` 포함 여부를 검사합니다. 최종 소스 ZIP을 새 폴더에 풀어 Node 279개와 구문 검사, 신규 단가 연결 UI를 다시 실행한 원문은 전체 묶음의 `verification/`에 포함합니다.

## 여전히 미검증

실제 사용자 데이터에서 신고한 현상의 원인, 실제 VS Code Extension Host 설치, macOS/Windows/WSL/SSH, 실제 Antigravity 앱 버전별 DB 의미, 실제 청구액, OS PiP 최상위 동작, 수백만 요청 성능과 외부 카탈로그/실제 자동 배포 다운로드는 이 테스트로 검증하지 않았습니다. ‘매칭 일치’는 모델·규칙 연결 검사 결과이지 실제 청구 일치 보증이 아닙니다.
